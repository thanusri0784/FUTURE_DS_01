# FUTURE_DS_01 - Business Sales Performance Analytics

# Objective

Analyze business sales data to identify revenue trends, top-selling products, profitable categories, and regional performance.

# Dataset

Sample Superstore Dataset

# Tool Used

Tableau Public

# Dashboard Components

- Sales by Category
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Top Products

# Key Insights

1. Technology category generated the highest sales.
2. Technology category generated the highest profit.
3. East region showed strong sales performance.
4. Monthly sales showed fluctuations and growth periods.
5. Top products contributed significantly to overall revenue.

# Files Included

- Tableau Dashboard (.twbx)
- Dashboard Screenshot
- Project Documentation

# Conclusion

The dashboard helps identify sales trends and business opportunities through data visualization.
